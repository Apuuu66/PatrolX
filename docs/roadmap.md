# PatrolX 路线图

本文档记录迭代计划和后续演进方向。长期架构约束见
[`.specify/memory/constitution.md`](../.specify/memory/constitution.md)。

## 当前状态

M0–M4 已完成：

- OpenAPI v1 契约。
- 本地离线全流程。
- 六类示例规则。
- 在线 API 与 SQLite 元数据。
- React 前端主要页面。
- 本地与在线模式共用页面和契约结果。

M5 主要能力已部分落地：

- structlog 结构化日志。
- Prometheus 指标。
- Dockerfile / docker-compose。
- 任务生命周期执行日志。
- 统一错误码枚举。

待补充：

- 浏览器全流程回归。
- 真实内网包格式持续对齐。
- Docker 环境实际验证。

## 迭代原则

- 契约先行。
- 示例先行。
- 从简优先。
- 本地模式先行验证规则。
- 在线模式扩展共享巡检能力。
- 性能优化在功能稳定后进行。

## 后续演进

### 跨任务趋势分析

目标：

- 按任务元数据聚合历史任务。
- 支持不同时间、版本下的 KPI、资源、告警和话统趋势。

设计支撑：

- 任务元数据键跨任务稳定。
- `metrics[].value` 数值化。
- `metrics[].series[]` 支持趋势。
- `SystemInspection.version` 承载版本。

可能形态：

- 新增跨任务聚合服务。
- 新增趋势查询接口。
- 新增趋势展示组件。
- 契约如发生破坏性变更，升级 API 版本。

### 规则管理增强

可能方向：

- 规则运行历史查看。
- 规则执行耗时分析。
- 只读元数据管理增强。
- 后续再评估在线启停和参数配置。

### 字典管理增强

可能方向：

- 字典项编辑界面。
- 字典引用校验。
- 更完整的导入/导出能力。

### 部署与运行增强

可能方向：

- 生产部署配置模板。
- 备份/恢复策略。
- 大包处理性能优化。
- 队列与并发模型评估。

以上能力均不改变当前 Constitution 中的离线优先、契约驱动、规则隔离和轻量默认约束。
