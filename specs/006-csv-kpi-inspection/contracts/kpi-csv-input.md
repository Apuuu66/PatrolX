# 契约：KPI CSV 输入

## 文件命名

```text
kpi-<domain>-<period>.csv
```

- `domain`: `api`、`media`、`call`
- `period`: `5`、`15`、`30`、`60`
- 文件必须位于任务现场的 `kpi/` 分类目录下；嵌套子包可引入中间目录。
- 扩展名必须为小写 `.csv`；文件名模板第一版区分大小写。

## 行结构

| 行 | 含义 | 约束 |
| --- | --- | --- |
| 1 | 测量集名称 | 非空；只取第一个字段并去除空白 |
| 2 | 测量对象/指标名 | 前 3 列固定；第 4 列起为指标名且不重复 |
| 3+ | 数据行 | 允许空行；非空行列数必须等于表头列数 |

表头前 3 列固定为：

```text
测量周期,开始时间,结束时间
```

## 数据行

| 列 | 字段 | 约束 |
| --- | --- | --- |
| 1 | `period_minutes` | 整数且等于文件名周期 |
| 2 | `start_at` | 可解析时间；naive 输入按配置时区转 UTC |
| 3 | `end_at` | 可解析时间；`end_at = start_at + period` |
| 4+ | `values[object]` | 数值可解析；与第 2 行指标名一一对应 |

示例：

```csv
呼叫会话统计
测量周期,开始时间,结束时间,呼叫请求,请求成功,请求失败,统计峰值,最大并发
15,2026-09-14 10:00:00,2026-09-14 10:15:00,1200,1170,30,100,88
```

## 错误处理

- 解码失败、缺少测量集、缺少表头、列数不一致、周期不匹配、时间不匹配、数值不可解析都必须生成结构化错误。
- 每个错误包含相对路径、行号（如适用）、错误码和中文 message。
- 单行错误不阻断同文件其他行；单文件错误不阻断同领域其他文件。
- 超过解析预算时生成 `resource_limit_exceeded`，规则状态为 `fail`，不得静默截断。
