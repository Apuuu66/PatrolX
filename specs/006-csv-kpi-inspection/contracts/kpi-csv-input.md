# 契约：KPI CSV 输入

## 文件命名

```text
kpi-<domain>-<period>.csv
```

- `domain`: `api`、`media`、`call`
- `period`: `5`、`15`、`30`、`60`
- 文件必须位于任务现场的 `kpi/` 分类目录下；嵌套子包可引入中间目录。
- 扩展名必须为小写 `.csv`；文件名模板第一版区分大小写。

## 行结构

表头不依赖固定列下标，但必须按列名包含：

| 列名 | 约束 |
| --- | --- |
| `测量开始时间` | 可解析时间 |
| `测量结束时间` | 可解析时间 |
| `周期(分钟)` | 整数且等于文件名周期 |
| 后续列 | KPI 指标名，且不重复 |

表头前允许元数据行；解析器扫描到第一行包含上述三个必填列名时停止扫描。元数据行使用 `key：value` 格式，其中 `测量单元名称` 作为测量集名称。

表头前的非指标上下文列（如 `服务名`、`实例`、`可信度`、`不可信原因`）保留在原始 CSV 中，但不进入指标值。

`周期(分钟)` 后面的所有列均为 KPI 指标。

```text
测量开始时间,测量结束时间,周期(分钟),<指标名...>
```

## 数据行

数据行列数必须等于表头列数。解析器按表头定位时间、周期和指标列：

| 字段 | 来源 | 约束 |
| --- | --- | --- |
| `start_at` | `测量开始时间` 列 | 可解析时间；naive 输入按配置时区转 UTC |
| `end_at` | `测量结束时间` 列 | 可解析时间；`end_at = start_at + period` |
| `period_minutes` | `周期(分钟)` 列 | 整数且等于文件名周期 |
| `values[object]` | `周期(分钟)` 后所有列 | 数值可解析；与表头指标名一一对应 |

示例：

```csv
设备类型：XXX
测量单元名称：呼叫会话统计
服务名,实例,可信度,不可信原因,测量开始时间,测量结束时间,周期(分钟),呼叫请求次数,呼叫请求成功次数,呼叫请求失败次数
BasicKpi,,可信,,2026-09-14 10:00:00,2026-09-14 10:05:00,5,100,100,0
```

## 错误处理

- 解码失败、缺少测量集、缺少表头、列数不一致、周期不匹配、时间不匹配、数值不可解析都必须生成结构化错误。
- 每个错误包含相对路径、行号（如适用）、错误码和中文 message。
- 单行错误不阻断同文件其他行；单文件错误不阻断同领域其他文件。
- 超过解析预算时生成 `resource_limit_exceeded`，规则状态为 `fail`，不得静默截断。
