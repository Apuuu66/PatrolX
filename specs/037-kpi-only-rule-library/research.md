# 阶段 0 研究：KPI-only 规则库收缩

## 决策 1：硬删除旧规则模块，而不是停用

- **决策**：删除 `app/inspectors/alarm/`、`config/`、`log/`、`resource/`、`traffic/` 及对应导入、测试和活动文档。
- **理由**：FR-002 明确禁止仅通过停用配置、隐藏入口或归档目录保留可执行能力。删除模块可让注册表、启停列表、执行计划和 API 目录天然收敛。
- **备选方案**：把所有旧代码加入 `disabled_rules`；仍可被重新启用或直接导入，不满足“彻底删除”。

## 决策 2：保留 hidden `pkg.extract.*` 与分类配置

- **决策**：保留 `app/inspectors/pkg.py` 的主包及 7 个分类解压规则，全部保持 `hidden=True`；保留 `deploy/config/classify_rules.yaml`。
- **理由**：它们不是普通巡检规则，而是安全解压、证据保留、文件落位和台账解析的基础设施。删除会违反 FR-003、FR-009、FR-010。
- **备选方案**：只保留主包解压、删除分类设施；会破坏台账、包证据和非 KPI 文件保留。

## 决策 3：历史结果读取与活动注册表解耦

- **决策**：`GET /api/v2/tasks/{task_id}/rules/{rule_code}` 直接按“SQLite → 现场 JSON → system 摘要”读取；只有结果不存在时返回 404，不先检查活动注册表。
- **理由**：历史证据的可追溯性不应依赖当前代码版本。规则模块删除后，已持久化结果仍必须可读，符合 FR-007、FR-008。
- **备选方案**：保留注册表检查；会让已删除规则的历史结果全部变成 404。

## 决策 4：重跑和增量重建继续使用注册表白名单

- **决策**：`POST /rerun`、增量 `/rebuild`、CLI 单规则入口继续先检查当前注册表；已删除代码返回 `unknown_rule`（或等价的明确未注册错误），不修改任务现场。
- **理由**：历史数据可读不等于历史代码可执行。白名单还能防止任意代码或旧实现被重新调用。
- **备选方案**：仅按历史 JSON 是否存在决定是否重跑；无法执行且会暴露不一致错误。

## 决策 5：规则分类枚举和展示组件继续兼容历史值

- **决策**：保留 `RuleCategory` 的 `log`、`traffic`、`alarm`、`config`、`resource` 等枚举值及历史分类展示能力；活动注册表与启停列表只暴露 KPI。
- **理由**：契约字段必须可解析旧结果，前端筛选、颜色、详情和历史统计也不应因枚举删除而失败；FR-012 要求兼容历史任务。
- **备选方案**：删除枚举值；历史 JSON 反序列化失败，违反契约兼容性。

## 决策 6：KPI 判定与版本不变

- **决策**：保留 `kpi.measurement_units` 的 `source_refs: [kpi_all]`、现有模式、逻辑和 `rule_version: 3.3.0`。
- **理由**：本功能只改变可用规则范围，不改变 KPI 判定逻辑，无需递增规则版本。
- **备选方案**：借机重构 KPI；扩大风险且违反“最小变更”。

## 决策 7：测试数据分层使用

- **决策**：活动执行断言只用 KPI；非 KPI 数据继续放在合成包中用于解压、分类、台账和历史兼容测试；注入式 executor/registry 测试可继续使用虚构规则；不提交或处理真实包。
- **理由**：既证明“非 KPI 文件保留但不触发规则”，又保持测试隔离和宪法要求。
- **备选方案**：清空非 KPI fixtures；会失去包处理与历史兼容覆盖。

## 决策 8：契约只调整描述，不改 Schema/版本

- **决策**：同步 `docs/api/openapi.yaml` 中规则结果读取、规则目录、重跑/重建的说明；Pydantic Schema、响应结构和 `/api/v2` 版本不变。
- **理由**：本次是既有能力范围收缩与历史读取语义澄清，不需要破坏性 API 变更。
- **备选方案**：升级 API 版本；对消费者造成无必要破坏。

## 决策 9：前端历史详情保持可读

- **决策**：保留规则详情页在 inspector 元数据缺失时的历史结果展示；相关 E2E 明确使用历史任务夹具，不暗示已删除规则仍为活动规则。
- **理由**：FR-007、SC-005 要求用户仍能查看历史结果；规则目录仍只显示 KPI。
- **备选方案**：规则详情依赖 `/inspectors` 才渲染；历史记录将不可用。
