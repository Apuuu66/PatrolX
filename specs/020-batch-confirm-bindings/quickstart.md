# 快速验证：指标绑定批量确认

## 前置条件

1. 使用 admin 账号访问 Web 界面。
2. 系统中存在多条已关联 ME 指标的候选绑定，以及未选中绑定。
3. 启动本地服务：`python build.py run`。

## 界面验证

1. 打开“测量单元”页面，进入“绑定关系”。
2. 勾选多条候选且已关联指标的绑定。
3. 点击“批量确认”，确认成功提示显示处理数量。
4. 列表刷新后：
   - 选中成功项状态变为“已确认”。
   - 未选中绑定状态、指标 ID 和来源信息不变。
5. 构造包含不存在绑定或缺少指标的混合选择时：
   - 界面显示成功数与失败数。
   - 失败项可看到绑定 ID 和原因。
   - 成功项仍然确认。
6. 对同 ME 指标、不同测量单元的候选绑定时：
   - 相关候选项确认失败。
   - 已有确认绑定不被取消或改写。

## 命令验证

```bash
python build.py lint
python build.py test
python build.py contract
python build.py gen-web-api
python build.py verify
```
