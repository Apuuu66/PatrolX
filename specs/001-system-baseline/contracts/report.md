# 报告契约：系统基线

## 目的

报告为维护者提供可读的巡检摘要，无需打开原始包文件。它补充但不替代 Web UI 中的任务/系统/规则下钻。

## 必须的报告内容

1. 任务标识和执行上下文。
2. 任务内系统元数据和包溯源。
3. 整体状态和 pass、warn、fail、error、skip 的汇总计数。
4. 规则状态摘要，包含运维相关的隐藏规则异常。
5. 含严重程度、来源位置、证据和建议的发现。
6. 含原因的跳过规则。
7. 可用时的执行时间或耗时。

## 基线约束

- 报告为在线预览的 HTML。
- PDF 导出不在范围内。
- 报告下载不在范围内。
- 报告不得暴露秘密或无关客户数据。
- 每条可操作发现必须保持可追溯到来源数据。
- 报告必须从契约结果和保留证据生成，而非临时的未持久化计算。

## 审查结果

一份报告可接受的标准是维护者能够判断：

- 巡检是否完成。
- 整体健康/状态分布。
- 哪些规则失败、告警、异常或跳过。
- 最重要的问题发生在哪里。
- 建议的后续行动是什么。
