# 实现计划：任务列表列宽压缩

**分支**：`036-task-list-column-compaction`（实现目标名；规划在 main 完成，实现阶段创建独立 worktree） | **日期**：2026-10-23 | **规格**：[spec.md](./spec.md)

**输入**：来自 `/specs/036-task-list-column-compaction/spec.md` 的功能规格

## 摘要

任务列表当前 8 个物理列、声明总宽 1530px，在 1440px 视口（可用约 1192px）必须靠表格内部横向滚动才能看到右侧列。本轮做一次纯展示层压缩：

1. **时间三列合一**：把"创建时间 / 最后运行 / 任务时长"合并为单个"时间"列（160px）——耗时为主信息、最后运行时间为次、创建时间为最次，完整时间走 Tooltip，等宽数字、不换行；运行中不显示上一次耗时，未运行显示占位。
2. **元数据收纳**：`MetadataList` 平铺上限由 5 项降为 3 项，其余进入既有"更多元数据"入口（含收纳项数、可复制、空值不渲染、行高不变）。
3. **宽度预算重排**：列宽收敛为 任务 240 / 状态摘要 150 / 数据准备 160 / 元数据 140 / 时间 160 / 操作 280，合计 1130px（1440 实测可用宽度 1142px，留 12px 余量）；表格 `scroll.x` 由 1530 降为 1130，配 `table-layout: fixed`，使 1440×900 一次看全全部列。
> **实现期实测修正（2026-10-23）**：规划期按“视口 − 侧栏 200 − Content 内边距 48”估算 1440 可用宽度为 1192px，未计入卡体内边距 48px 与卡片边框 2px；实现期在浏览器实测得到 1440 下表格容器 `.ant-table-content` 可用宽度为 **1142px**（与 `specs/031-ui-information-hierarchy/verification.md` 记录的 1142 / 1142 完全一致）。据此按 research R2 的回退顺序，把列宽合计由 1160px 下调为 **1130px**（状态摘要 160→150、数据准备 170→160、元数据 150→140；任务 240、时间 160、操作 280 保持不变，操作列绝不压缩），1440 下留 12px 余量。需求口径（1440×900 无内部横向滚动）未变。


不改任何功能语义：操作列仍固定右侧、操作平铺常驻、无任务级"重跑"、重建与删除保留二次确认、删除失败就地重试；筛选、搜索、分页、轮询、深链、上传流程、数据准备列内弹层全部保持。

全部改动限定在前端展示层与 `docs/design/DESIGN.md`，不新增或修改 OpenAPI 契约、不改后端执行链路与数据模型。

## 技术上下文

**语言/版本**：TypeScript 5.x（前端）；文档为 Markdown。

**主要依赖**：React 18、Vite、Ant Design 5、dayjs；测试为 Vitest + Testing Library + Playwright。不新增依赖。

**存储**：不适用（无新增持久化；展示层直接消费既有 `TaskSummary` 字段）。

**测试**：`npx vitest run`（组件与工具单测）、`npx playwright test`（E2E 与视口回归）、`python build.py lint / test / web-build / e2e`（合入门禁）。

**目标平台**：桌面浏览器 1280px ~ 1920px（Chrome/Chromium 为主）。

**项目类型**：Web 前端（离线巡检系统展示层）。

**性能目标**：无新增接口调用；时间与元数据均为纯格式化，渲染路径不增加网络请求或大数据遍历。压缩列宽后不改变首屏行数（行高不变）。

**约束条件**：

- 不修改 `docs/api/openapi.yaml`；不新增接口端点、不新增前端 API 调用。
- 1440×900 下任务列表不出现表格内部横向滚动；1280 允许表格内部横向滚动但不得出现页面级横向滚动。
- 操作列不低于 280px 且固定右侧；时间与元数据不得成为"需要展开才能知道关键信息"的隐藏区。
- 既有筛选、搜索、分页、轮询、深链、上传、报告、（仅规则详情页的）单规则重跑、重建与删除确认行为不变。
- 1920px 内容宽度沿用 `.app-shell-inner` 的 1600px 上限。

**规模/范围**：3 个用户故事、22 条功能需求；涉及 1 个页面、1 个展示组件、1 个工具函数、1 份样式表与 1 份设计规范。
