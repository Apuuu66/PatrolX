# 实现计划：任务详情统计数字过滤

**分支**：`003-task-detail-count-filter` | **日期**：2026-09-12 | **规格**：[spec.md](spec.md)

**输入**：来自 `/specs/003-task-detail-count-filter/spec.md` 的功能规格

## 摘要

任务详情页总览区的 5 个规则状态数量（通过、告警、失败、异常、跳过）从纯展示改为可点击的过滤入口。点击后全局过滤所有分类分组中对应状态的规则；再次点击取消过滤。总览状态数量由详情页可见普通规则列表推导，隐藏内部规则（如解压）不参与统计。分类分组标题数字反映当前过滤范围。本功能为纯前端交互变更，不涉及后端接口、契约或存储变更。

## 技术上下文

**语言/版本**：TypeScript（前端）+ Python 3.11+（后端，本功能不变更）

**主要依赖**：React 18 + Ant Design 5 + Vite（前端）；FastAPI + Pydantic v2（后端，本功能不变更）

**存储**：SQLite + 文件存储（本功能不变更）

**测试**：Vitest（前端单元测试）；pytest（后端，本功能不变更）

**目标平台**：桌面浏览器（桌面优先，不做移动端适配）

**项目类型**：全栈 Web 应用（本功能仅前端）

**性能目标**：过滤和取消过滤应即时响应（单次状态变更，无网络请求）

**约束条件**：离线优先；不修改任务结果数据、规则结果契约或服务端存储

**规模/范围**：单任务详情页内交互；任务规则数通常在几十到百级
