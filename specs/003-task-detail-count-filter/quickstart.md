# 快速验证指南：任务详情统计数字过滤

## 前提条件

1. 后端依赖已安装（`make install`）
2. 至少一个已完成巡检的任务存在于 `output/` 目录中
3. 任务中包含多种状态的规则结果（至少包含通过和告警/失败）

## 启动

```bash
make run
```

打开浏览器访问 `http://localhost:5173/tasks`。

## 验证场景

### 场景 1：点击状态数量过滤规则列表

1. 在任务列表中点击一个包含多种状态规则的任务，进入任务详情页。
2. 确认总览区显示通过、告警、失败、异常、跳过 5 个状态数量。
3. 点击"告警"数量。
4. **预期**：规则列表只显示状态为告警的规则；无告警规则的分类分组被隐藏；分组标题中的数字只统计告警规则；总览区的告警数量保持不变。

### 场景 2：再次点击取消过滤

1. 在场景 1 的基础上，再次点击"告警"数量。
2. **预期**：过滤取消，规则列表恢复显示全部可见规则，所有分类分组重新出现。

### 场景 3：切换过滤状态

1. 点击"告警"数量完成过滤。
2. 点击"失败"数量。
3. **预期**：过滤从告警切换为失败，规则列表只显示失败规则。

### 场景 4：点击数量为 0 的状态

1. 找到一个某个状态数量为 0 的任务详情。
2. 点击该状态数量。
3. **预期**：规则列表区域显示明确的空状态提示，不显示任何规则。

### 场景 5：轮询刷新后过滤保持

1. 点击某个状态数量激活过滤。
2. 触发重跑全部规则，使任务进入 running 状态。
3. 等待轮询刷新任务数据。
4. **预期**：过滤条件保持不变；列表和总览数量反映最新任务结果。

