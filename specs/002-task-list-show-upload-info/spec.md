# 功能规格：任务列表展示上传时选择的信息

**功能分支**：`002-task-list-show-upload-info`

**创建日期**：2026-09-12

**状态**：草稿

**输入**：用户描述："任务列表里展示上传时选择的信息，便于区分更明显"

## 用户场景与测试 *(必填)*

### 用户故事 1 - 在任务列表中查看上传时选择的省份、运营商、产品形态和版本（优先级：P1）

维护者在任务列表页浏览多个任务卡片，每张卡片上直接展示该任务上传时选择的省份、运营商、产品形态和版本信息，无需点击进入详情页即可快速区分不同来源的任务。

**优先级理由**：这是核心改进点——维护者日常通过任务列表区分不同客户/环境的任务，缺少这些信息需要逐个点击详情才能判断。

**独立测试**：上传一个包并选择省份、运营商和产品形态，任务列表卡片上直接显示所选标签。

**验收场景**：

1. **给定**用户上传数据包时选择了省份、运营商、产品形态和版本，**当**任务出现在任务列表中，**则**卡片上展示对应的省份、运营商、产品形态和版本信息。
2. **给定**用户上传数据包时未选择任何可选信息，**当**任务出现在任务列表中，**则**卡片上不展示空白标签，仅展示已有信息。

---

### 用户故事 2 - 上传时选择产品形态（优先级：P2）

维护者在上传数据包的表单中，可以选择产品形态。产品形态选项来自字典管理模块的产品形态字典。

**优先级理由**：产品形态是区分任务来源的重要维度，上传表单目前缺少该字段，补齐后与省份/运营商/版本一致。

**独立测试**：打开上传对话框，可见产品形态下拉框且选项来自字典；选择后提交成功。

**验收场景**：

1. **给定**字典管理中已配置产品形态字典，**当**用户打开上传对话框，**则**产品形态下拉框展示字典选项。
2. **给定**用户选择了产品形态并提交，**当**任务创建完成，**则**API 返回的任务摘要中包含所选产品形态。

---

### 边界情况

- 上传时部分字段未选择（例如只选了省份但没选运营商）：列表仅展示已选择的字段，未选择的字段不显示为空占位。
- 历史任务没有存储上传时选择的信息（旧数据）：列表对这些任务不展示对应标签，不报错。
- 字典管理中产品形态字典为空：上传表单中产品形态下拉框无选项但可见，不报错。

## 需求 *(必填)*

### 功能需求

- **FR-001**：任务列表 API（`GET /api/v1/tasks`）返回的每个任务摘要必须包含上传时选择的省份、运营商、产品形态和版本信息。
- **FR-002**：任务列表前端卡片必须在任务名称附近以标签形式展示省份、运营商、产品形态和版本信息。
- **FR-003**：未选择的可选信息不得在卡片上渲染为空标签或占位符。
- **FR-004**：上传表单必须新增产品形态下拉框，选项来自字典管理的产品形态字典。
- **FR-005**：上传 API（`POST /api/v1/tasks`）必须接受 `product` 表单字段并存储到任务的客户上下文中。
- **FR-006**：OpenAPI 契约 `docs/api/openapi.yaml` 必须同步更新 `TaskSummary` Schema 新增客户上下文字段，以及 `createTask` 操作新增 `product` 表单参数。
- **FR-007**：后端 Pydantic Schema 必须与 OpenAPI 契约保持一致。

### 关键实体

- **TaskSummary**：任务摘要，新增 `customer_province`、`customer_operator`、`customer_product`、`customer_version` 字段（均为可选字符串）。
- **InspectionTask（DB）**：已有 `customer` JSON 列和 `version` 列存储上传时信息，无需变更存储模型。

## 成功标准 *(必填)*

### 可度量结果

- **SC-001**：用户上传包并选择省份和运营商后，任务列表卡片上可见所选省份和运营商。
- **SC-002**：用户上传包且不选择任何可选信息后，任务列表卡片上无空标签。
- **SC-003**：API 返回的任务摘要包含新增的客户上下文字段且与上传时选择一致。
- **SC-004**：上传表单可见产品形态下拉框且选项来自字典；选择后提交成功且列表可见。

## 假设

- 上传时已存在的字典选择（省份/运营商/版本）已存储在 DB 的 `customer` 字段和 `version` 字段中。
- `product` 字段 DB 结构支持存储；本规格补齐上传表单字段和 API 参数。
- 不需要新增筛选或排序能力，仅展示。
