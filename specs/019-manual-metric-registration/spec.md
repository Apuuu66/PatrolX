# 规格：人工注册指标

**功能分支**：`019-manual-metric-registration` | **日期**：2026-09-22

**状态**：已被 `specs/021-kpi-auto-catalog/spec.md` 部分替代；未注册列可自动入库并默认参与巡检，人工注册仅作为异常修正能力。

## 价值与范围

维护人员导入资源 CSV 后，任务包中仍可能出现资源目录未覆盖的指标列。当前这些列只能显示为“未注册指标”，必须重新整理 CSV 再导入，操作成本高。本功能允许维护人员在指标绑定现场直接注册新的 ME 指标，并在界面上继续维护其名称和状态；绑定确认仍由人工控制，系统不得自动把未注册列变成可巡检指标。

## 用户故事

### US1：从任务现场注册未注册指标

作为巡检维护人员，我希望在查看未注册指标绑定时直接补录 ME 指标，这样无需暂停排查、重新准备完整资源 CSV。

1. **给定** 某个绑定候选缺少指标资源，**当** 维护人员选择注册指标，**则** 系统展示注册表单。
2. **给定** 注册表单，**当** 页面打开，**则** 系统预填指标中文名和展示单位；中文名来自去掉展示单位括号后的 CSV 基础列名，展示单位来自原列名尾部括号。
3. **给定** 维护人员确认注册信息，**当** 提交成功，**则** 系统创建一条 ME 指标资源，并把该绑定候选关联到该资源。
4. **给定** 注册成功，**当** 返回绑定列表，**则** 绑定显示为已关联指标，但状态仍为候选，未人工确认前不参与巡检。

### US2：标识人工注册指标

作为巡检维护人员，我希望区分人工注册指标和 CSV 导入指标，这样能判断数据来源，也便于现场沟通。

1. **给定** 一个由人工注册创建的 ME 指标，**当** 系统创建资源，**则** 必须生成以 `ME__MANUAL_` 开头、带唯一后缀的资源 ID；该 ID 在列表中可直接识别为人工注册。
2. **给定** 一个 ME 指标 ID 以 `ME__MANUAL_` 开头，**当** 进入指标编辑入口，**则** 系统允许修改其中文名、英文名和启用状态。
3. **给定** 一个 ME 指标 ID 不是 `ME__MANUAL_` 前缀，**当** 用户尝试通过编辑接口修改，**则** 系统拒绝并说明仅人工注册指标支持编辑。
4. **给定** 一个人工注册指标，**当** 在界面展示，**则** 系统显示“人工注册”标识。

### US3：维护人工注册指标

作为巡检维护人员，我希望在导入后发现拼写或英文翻译不准确时能直接修改指标描述，这样资源目录能保持可用。

1. **给定** 一个人工注册指标，**当** 维护人员修改中文名、英文名或启用状态并保存，**则** 系统只更新这些描述字段。
2. **给定** 一个人工注册指标，**当** 用户尝试修改资源 ID、原始 CSV 列名、基础列名或绑定来源，**则** 系统不提供修改能力。
3. **给定** 用户提交的新中文名已被另一个 ME 指标使用，**当** 保存，**则** 系统拒绝保存并提示同名指标已存在。
4. **给定** 用户修改了指标中文名或英文名，**当** 保存成功，**则** 已有绑定关系和确认状态保持不变。

### US4：防止重复和脏数据

作为巡检维护人员，我希望注册流程能识别已有指标，这样不会因为多次处理任务现场而产生重复资源。

1. **给定** 用户提交的中文名已经存在 ME 指标，**当** 注册，**则** 系统要求维护人员选择绑定已有指标或修改中文名。
2. **给定** 用户选择绑定已有指标，**当** 提交，**则** 系统更新当前绑定候选的指标资源，不创建新资源。
3. **给定** 系统为人工注册生成资源 ID，**当** 生成结果与既有资源 ID 冲突，**则** 系统生成新的唯一后缀，不覆盖或复用既有资源。
4. **给定** 未注册列由多个任务发现，**当** 用户为其中一条注册指标，**则** 其他未注册绑定不自动修改。

## 功能需求

- **FR-001**：系统必须允许维护人员从未注册指标绑定创建 ME 指标资源。
- **FR-002**：系统必须在注册表单中预填基础列名和展示单位。
- **FR-003**：系统必须为人工注册指标生成 `ME__MANUAL_` 前缀加唯一后缀的资源 ID，保证 ID 唯一且来源可识别。
- **FR-004**：系统必须在人工注册成功后把该绑定候选关联到新指标资源。
- **FR-005**：系统必须保持绑定状态为候选，直到维护人员显式确认。
- **FR-006**：系统必须支持编辑 `ME__MANUAL_` 前缀指标的中文名、英文名和启用状态。
- **FR-007**：系统必须拒绝编辑非 `ME__MANUAL_` 前缀指标的中文名和英文名。
- **FR-008**：系统必须禁止修改资源 ID、原始列名、基础列名和绑定来源。
- **FR-009**：系统必须保证同类 ME 指标中文名唯一，已有同名资源时不得创建重复资源。
- **FR-010**：系统必须允许维护人员选择已有 ME 指标来完成当前未注册绑定的关联。
- **FR-011**：系统必须在界面展示人工注册标识。
- **FR-012**：系统必须保留未注册列、候选绑定、冲突绑定和确认绑定的现有处理语义。

### 关键实体

- **人工注册指标**：由绑定现场创建的 ME 资源，ID 以 `ME__MANUAL_` 开头并带唯一后缀，中文名在同类型指标中唯一。
- **未注册绑定**：缺少 `metric_resource_id` 的指标绑定候选，保留原始列名、基础列名、展示单位和来源任务信息。
- **已有 ME 指标**：资源目录中既有的 ME 资源，可被人工选择用于完成未注册绑定，但不会因此改变其资源 ID。

## 成功标准

### 可度量结果

- **SC-001**：维护人员处理一条未注册指标绑定时，可以在不超过 1 分钟的表单操作内完成指标注册。
- **SC-002**：注册成功后，该绑定的指标资源由空变为有值，且绑定状态仍为候选。
- **SC-003**：人工注册指标在资源标识和界面标识中均可被识别。
- **SC-004**：重复中文名、修改非人工指标、修改不可变字段的尝试都会被明确拒绝；生成 ID 不会复用既有资源 ID。
- **SC-005**：指标编辑后，其已有绑定的原始列名和确认状态保持不变。

## 假设

- 人工注册仅针对 ME 指标，不新增测量单元和单位资源；资源 ID 由系统生成，资源 ID 创建后不可修改。
- 英文名在人工注册时可以留空，后续可编辑补充。
- 资源 ID 一旦创建不可变更；维护人员如果确实需要不同 ID，应创建新资源并重新确认绑定。
- 本功能不改变 CSV 导入按中文名合并资源的现有规则。
- 本功能不自动确认绑定，也不自动批量修改其他任务中的相同未注册列。
