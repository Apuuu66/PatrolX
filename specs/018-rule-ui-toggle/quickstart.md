# 快速验证：界面规则启停

## 前置条件

1. 启动本地服务并登录管理员账号。
2. 进入规则管理页面。
3. 当前配置中的预置停用规则应显示为停用。

## 主流程验证

### 1. 查看状态

- 规则列表展示规则代码、名称、分类、优先级、启用状态。
- 隐藏规则不可切换；如果页面包含隐藏规则，开关应为禁用状态。

### 2. 停用规则

1. 选择一条启用中的普通规则。
2. 将开关切换为停用。
3. 页面提示成功，且刷新后状态保持停用。
4. 上传一个包含该规则目标文件的新任务包。
5. 新任务结果不包含该规则；剩余启用规则正常执行。
6. 已有任务结果保持不变。

### 3. 重新启用规则

1. 将同一条规则切换回启用。
2. 页面提示成功，且刷新后状态保持启用。
3. 再次创建新任务，该规则结果重新出现。

### 4. 单规则重跑保护

1. 停用一条规则。
2. 在既有任务上尝试单规则重跑该规则。
3. 系统返回明确失败原因，不更新该任务规则结果。

### 5. 服务重启

1. 停用若干规则。
2. 重启服务。
3. 规则列表状态与重启前一致。
