# 研究记录：压缩项解压跳过与白名单策略

## 1. 策略存放位置

**Decision**：新增独立项目级配置 `deploy/config/extract_policy.yaml`。

**Rationale**：解压安全策略与文件分类规则关注点不同。独立文件可以独立校验、审计和演进，避免 `classify_rules.yaml` 继续膨胀。

**Alternatives considered**：
- 扩展 `classify_rules.yaml`：减少文件数量，但会把“文件属于哪类”和“是否展开”混在一个契约里。
- 任务级 API 参数：灵活，但澄清结论明确使用项目级配置，且会引入公共 API 和前端契约变更。
- 包内配置文件：无法信任不可控客户包，且主包本身必须先解压才能读取配置，存在安全歧义。

## 2. 匹配机制

**Decision**：目录前缀匹配 + 配置驱动的名称关键字白名单；两者都基于任务内归一化相对路径。

**Rationale**：目录前缀直接满足“某个路径下不展开”的语义，测试直观、误匹配风险低。名称关键字可保护 `alarm` 等关键内容，避免维护者穷举深层路径。

**Alternatives considered**：
- Glob/正则：表达力更强，但更容易写出意外越界或过度匹配模式，也会增加校验负担。
- 只支持精确路径：无法覆盖目录及其全部子路径，不符合用户场景。
- 内容识别：需要先解压才能判断，与跳过解压目标冲突。

## 3. 白名单优先级

**Decision**：白名单优先于 `nested.skip_all` 和 `nested.skip_paths[]`。

**Rationale**：跳过是成本优化，白名单是证据保护。安全语义上应先判断是否必须保留关键内容，再判断是否可以跳过。

**Alternatives considered**：
- 按配置顺序决定优先级：行为难以推断，配置重叠时结果不可预期。
- 跳过优先：会静默丢弃白名单意图，违反告警证据场景。

## 4. 被跳过项的落位

**Decision**：把被跳过压缩项保留为 category 现场中的最终文件；`.main/` 中原始证据不变。

**Rationale**：这使该项仍可通过任务文件清单和来源关系追溯，同时不会把中间压缩包从证据现场删除。对嵌套在现场内的压缩项可原地保留，避免重复复制。

**Alternatives considered**：
- 只保留在 `.main/`，不进入 category：普通规则和清单无法看到最终文件，跳过状态与巡检输入不一致。
- 删除被跳过项：破坏证据可追溯性，违反保留策略。
- 修改压缩包为占位文件：改写现场语义且丢失原始证据。

## 5. manifest 兼容策略

**Decision**：保持 manifest v3，新增可选 `policy` 节、`skipped` 状态和策略原因字段；旧 manifest 无 `policy` 节时仍可复用。

**Rationale**：旧现场是兼容基线，策略变更不重建已有任务。新增内部字段不破坏公共 API，且能记录新状态。

**Alternatives considered**：
- 升级 manifest v4：结构变更更清晰，但会迫使旧任务重建或写迁移器，收益不足。
- 用独立策略文件：需要额外一致性和清理逻辑，容易与 manifest 失配。

## 6. 普通文件审计

**Decision**：压缩项和 gzip 的策略结果写入 manifest；普通文件白名单命中写结构化日志，manifest `policy.counters` 保存汇总计数。

**Rationale**：普通文件本来就会按分类拷贝，全量路径入 manifest 可能造成体积和敏感路径风险；结构化日志仍满足逐项追溯需求。

**Alternatives considered**：
- 全部白名单文件写入 manifest：审计集中但可能显著扩大任务元数据。
- 只记录计数：无法逐项排查，不足以满足审计场景。

## 7. 无匹配规则的提示

**Decision**：普通规则仍不改实现；执行器在无匹配且同 category 存在策略跳过记录时，在既有 `skip_reason` 中补充可读说明。

**Rationale**：这满足“策略导致无匹配不能静默通过”的目标，也不引入规则间依赖或公共 Schema 破坏。

**Alternatives considered**：
- 新增公共字段：需要同步 OpenAPI、Schema 和前端客户端，超出本功能必要范围。
- 让规则读取 manifest：破坏“规则只读取匹配文件或私有 prepared 数据”的边界。

## 测试风险

| 风险 | 缓解 |
| --- | --- |
| 前缀误匹配 | 统一目录前缀必须以 `/` 结尾；测试区分 `0/` 与 `0a/`。 |
| 关键字过宽 | 关键字配置化并审计命中；测试提供明显样例。 |
| 跳过时内容嗅探 | 跳过分类只看来源文件名和父级分类，不读取成员。 |
| 目标冲突 | 不覆盖目标，记录失败并与策略跳过区分。 |
| 策略变更误重建 | manifest 可复用时不比较策略 fingerprint；测试验证不自动重建。 |
